# Contributing

All contributors are welcome. Please use issues and pull requests to contribute to the project. Commit messages use `fix:`, `feat:` or `BREAKING CHANGE:`. Release Please writes [CHANGELOG.md](CHANGELOG.md) from those messages.

## Release process

Merging the release pull request tags the release and publishes the GitHub Release. The settings that pull request needs are in [Releases](README.md#releases). Confirm the build is [passing in GitHub Actions](https://github.com/__GITHUB_USERNAME__/xxPROJECTxNAMExx/actions) before merging it.
